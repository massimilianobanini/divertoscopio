# Visual Hammer — Divertoscopio

Il Visual Hammer del Divertoscopio mette insieme due elementi in un unico segno semplice:

- un **mirino / strumento di messa a fuoco**;
- un **sorriso** integrato.

L'idea da rendere visibile è: **mettere a fuoco il divertimento**.

Il segno è deliberatamente **agnostico rispetto al d20 e ai singoli sistemi di GDR**. Non deve essere trasformato in un dado, drago, spada o altro simbolo legato a un singolo gioco.

## Colore principale

**Verde lime/elettrico — `#45DA02`**

Resta il riferimento cromatico del segno. L’asset principale usa uno sfondo nero/scuro e una resa luminosa del verde.
