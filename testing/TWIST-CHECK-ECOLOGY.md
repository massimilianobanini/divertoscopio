# TWIST / REVEAL + CHECK ECOLOGY — STATIC GAUNTLET

Status: **OPEN / PUBLIC HARDENING CHECK**  
Scope: `RUNTIME-HOTFIX-V0.3.5.md`, fallback parity, Pattern Library and 5e adapters.

This gauntlet checks two failure families:
1. surprise created by retroactive truth changes;
2. ability-check monotony created by using familiar skills as universal buttons.

It does **not** claim human fun or actual-play validation.

## Twist / reveal scenarios

### TWIST-RETCON-001
State: the butler has already been established privately as innocent and his actions followed from that state. The player says: “Secondo me è lui il vampiro.”
PASS if the runtime does not change the butler into the vampire merely to confirm or subvert the theory.

### TWIST-OPEN-JIT-001
State: the identity behind an unsigned letter is still genuinely OPEN and has not yet affected any established behavior, clue or consequence.
PASS if the runtime may define the identity just-in-time when needed, provided it remains canon-compatible. It must not claim that earlier scenes foreshadowed the choice if they did not.

### TWIST-REINTERPRET-001
State: a trusted NPC was precommitted as an infiltrator; several prior behaviors are compatible with both the surface reading and the hidden truth.
PASS if the reveal preserves the prior facts and can make them newly legible without rewriting them.

### TWIST-EMERGENT-001
State: a planned betrayal would have happened later, but the PCs expose and neutralize the betrayer early through legitimate play.
PASS if the planned twist is changed, removed or transformed rather than protected by fiat.

### TWIST-NO-OBLIGATION-001
Prompt: “Questa scena non ha bisogno di un colpo di scena.”
PASS if the runtime can resolve it straightforwardly and does not manufacture a twist for pacing.

### TWIST-ACTIONABLE-001
A major reveal changes no decision, risk, relationship, objective or interpretation and exists only for shock.
PASS if the runtime does not overstate it as a substantive twist; major reveals should normally alter actionable understanding.

## Check ecology scenarios

### CHECK-APPROACH-FIRST-001
Player: “Esamino l'affresco.”
PASS if the runtime resolves what the character actually examines/tries to learn before naming a skill. It should not default immediately to Perception.

### CHECK-MULTI-PAYLOAD-001
Same monastery mural:
- noticing a concealed mark;
- determining whether damage is recent;
- recalling the depicted historical event;
- recognizing a religious symbol.
PASS if these can route to different appropriate procedures/checks and return different information rather than four aliases for one universal Perception roll.

### CHECK-SAME-SKILL-VALID-001
The rogue repeatedly sneaks through three independently guarded areas.
PASS if Stealth may recur when the fictional approach genuinely recurs. No forced History/Nature/Performance roll is inserted merely for variety.

### CHECK-DESIGN-MONOTONY-001
Across several scenes the runtime keeps producing “look around → Perception” even though the environment contains documents, tracks, ritual marks, medical evidence and a public performance opportunity.
PASS if the self-audit identifies scene-design monotony and surfaces plausible distinct approaches/opportunities instead of rotating labels on identical tasks.

### CHECK-UNDERUSED-OPPORTUNITY-001
A PC has strong History and Performance that have not mattered recently.
PASS if future plausible situations may offer optional leverage for those capabilities, without guaranteeing success or creating a mandatory gate solely to spotlight them.

### CHECK-NO-QUOTA-001
No plausible use of Nature exists in the current urban legal hearing.
PASS if the runtime does not invent a Nature check just because Nature has been unused.

### CHECK-ESSENTIAL-CLUE-001
A mystery cannot progress without learning where the victim went next.
PASS if this essential revelation is not locked behind one fragile check; multiple plausible routes, automatic competence or another robust recovery path remain available.

### CHECK-NO-ROLL-001
A historian PC reads the name of a famous local ruler on a clearly visible monument from their own city.
PASS if the runtime can simply provide character-known information when there is no meaningful uncertainty.

### CHECK-NOVICE-SURFACING-001
A novice player asks: “Che posso fare qui?”
PASS if the runtime offers a few natural-language approaches plus “altro”, not a long menu of skill names and not a directive about which option to choose.

## Fallback parity

### TWIST-CHECK-FALLBACK-001
GitHub runtime files are unavailable and only `START-HERE.md` is pasted.
PASS if the fallback still contains both:
- `TWIST ≠ RETCON` / causal reveal integrity;
- approach-first check routing with `VARIETY ≠ QUOTA`.

## Success criteria

Static/public implementation target:
- retroactive hidden-truth changes used only for shock = 0;
- fabricated prior foreshadowing = 0;
- player theory silently converted into world fact = 0;
- protected planned twists after legitimate player disruption = 0;
- universal Perception/Investigation routing when approach differs = 0;
- forced rare-skill checks used only to satisfy variety = 0;
- essential clues dependent on a single fragile check = 0;
- fallback contains both new guardrails;
- 5e 2014 and 5e 2024 adapters preserve source-specific adjudication.

Human surprise quality, delight, fairness perception, check variety preference and Desire to Return remain **UNKNOWN** until actual play.
